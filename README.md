## Шаг 2: Как работать

У вас будет **два окна**:
1. **Терминал** — для запуска тестов: `npm test -- task1`
2. **Браузер** — для визуального результата: `npm run dev` → откроется `http://localhost:5173`

Рабочий процесс:
1. Откройте файл задания в `src/tasks/`.
2. Прочитайте TODO-комментарии.
3. Напишите решение.
4. Запустите тесты: `npm test -- taskN`
5. Откройте браузер (`npm run dev`) и проверьте, что интерфейс работает.

## Шаг 3: Задания

### Задание 1: Интерфейсы (30 мин)
**Файл:** `src/tasks/task1-types.ts`
**Задача:** Описать модель каталога книг.
1. Объявите интерфейс `Book` (id, title, authors, year?, rating?).
2. Объявите тип `Catalog` как `Record<string, Book>`.
3. Объявите тип `BookFilter` как функцию `(book: Book) => boolean`.
4. Реализуйте `formatBook(book: Book): string` — формат: `"Title (Year) — Authors"`.
5. Реализуйте `calculateAverageYear(books: Book[]): number`.

**Проверка:** `npm test -- task1`
**В браузере:** вы увидите отформатированный список книг на странице.

---

### Задание 2: Функции работы с каталогом (45 мин)
**Файл:** `src/tasks/task2-functions.ts`
**Задача:** Написать функции для управления каталогом.
1. `addBook(catalog: Catalog, book: Book): Catalog` — добавить книгу, вернуть новый каталог (не мутировать старый!).
2. `removeBook(catalog: Catalog, id: string): Catalog` — удалить книгу по id.
3. `getBook(catalog: Catalog, id: string): Book | undefined` — найти книгу.

**Проверка:** `npm test -- task2`
**В браузере:** пока ничего не меняется, но функции готовы к интеграции.

---

### Задание 3: Фильтрация (50 мин)
**Файл:** `src/tasks/task3-filters.ts`
**Задача:** Реализовать фильтры для поиска книг.
1. `filterByAuthor(authorName: string): BookFilter` — книга подходит, если автор есть в списке.
2. `filterByMinYear(year: number): BookFilter` — книга подходит, если год >= year.
3. `filterByMinRating(rating: number): BookFilter` — книга подходит, если рейтинг >= rating.
4. `applyFilters(books: Book[], filters: BookFilter[]): Book[]` — применить все фильтры.

**Проверка:** `npm test -- task3`
**В браузере:** появятся рабочие поля фильтрации — введите имя автора или год, нажмите "Применить", список обновится.

---

### Задание 4: Интеграция с DOM (60 мин)
**Файл:** `src/tasks/task4-integration.ts`
**Задача:** Связать форму на странице с логикой.
1. `createBookFromForm(formData: FormData): Book` — создать объект Book из данных формы (сгенерировать id через `crypto.randomUUID()`).
2. В `src/main.ts` допишите обработчики:
   - При отправке формы — создать книгу и добавить в каталог.
   - При клике "Применить фильтры" — отфильтровать и перерисовать список.

**Проверка:** `npm test -- task4`
**В браузере:** полноценное приложение — добавляйте книги, фильтруйте, удаляйте.

##  Частые проблемы

- **`npm run dev` не запускается:** убедитесь, что выполнили `npm install`.
- **Браузер показывает пустую страницу:** откройте консоль браузера (F12) — там будет ошибка.
- **Тесты проходят, но в браузере ничего не работает:** проверьте, что вы правильно подключили функции в `main.ts`.
- **TypeScript ругается на `document.getElementById`:** используйте `as HTMLInputElement` или `!` (non-null assertion).
